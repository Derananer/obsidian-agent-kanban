# Как работать с доской

Agent Kanban — это канбан-борда, которая живёт прямо в файловой системе вашего vault.
**Папки = колонки. Markdown-файлы = задачи.**

---

## Структура борды

```
board/
├── epics/           ← эпики (крупные темы)
├── 1-backlog/       ← задачи в очереди
├── 2-in-progress/   ← задачи в работе
└── 3-done/          ← выполненные задачи
```

Порядок колонок определяется числовым префиксом папки.
Можно добавлять свои колонки — например `3-review/`, `4-testing/`.

---

## Задачи

### Создать задачу

Нажмите **+** рядом с названием колонки в заголовке борды.
Заполните форму и нажмите **Save**.

Или создайте `.md` файл вручную в нужной папке:

```markdown
---
title: Название задачи
priority: high
tags: [бэкенд, авторизация]
created: 2026-04-05
due: 2026-04-15
epic: "Auth"
---

Описание задачи.
```

### Редактировать задачу

Кликните на карточку — откроется модальное окно редактирования.

### Переместить задачу между колонками

Перетащите карточку мышью в другую колонку.

---

## Эпики

Эпик — это крупная тема, объединяющая несколько задач.
Борда отображается в **swimlane-режиме**: каждый эпик — горизонтальная полоса через все колонки.

### Создать эпик

Создать `.md` файл в папке `board/epics/`:

```markdown
---
title: Auth
priority: high
tags: [безопасность]
due: 2026-04-30
---

Описание эпика.
```

Поле `title` — это имя, которое используется в задачах.

### Привязать задачу к эпику

В задаче указать:

```yaml
epic: "Auth"
```

Значение должно совпадать с `title` файла эпика (регистр не важен).

### Перенести задачу в другой эпик

Перетащить карточку в другую строку эпика.

### Свернуть / развернуть эпик

Нажать стрелку **▼** слева от названия эпика.

## Зависимости

Задача может зависеть от других задач.
Пока зависимость не выполнена — карточка показывает индикатор блокировки.

### Добавить зависимость

В форме редактирования заполнить поле **Depends on** — имена файлов через запятую, без `.md`:

```yaml
depends_on: [auth-login-form, setup-database]
```

### Индикаторы на карточке

| Индикатор | Значение |
|---|---|
| 🔒 красная полоса | задача-блокер найдена, но ещё не выполнена |
| ⚠️ оранжевая полоса | задача-блокер не найдена на доске |

Когда задача-блокер перемещается в done-колонку, блокировка снимается автоматически.

---

## Приоритеты

Приоритет отображается цветной полосой по левому краю карточки:

| Цвет | Приоритет |
|---|---|
| Красная | critical |
| Оранжевая | high |
| Жёлтая | medium |
| Серая | low |

---

## Агенты

Если задачу выполняет AI-агент, он проставляет себя в поле `agent`:

```yaml
agent: backend-agent
agent_status: busy
```

На карточке отображается имя агента и статус:

| Иконка | Статус |
|---|---|
| 🟢 | busy — активно работает |
| 🟡 | idle — приостановлен |
| ⚪ | inactive — не назначен |

---

## Советы

- **Задачи без эпика** всегда видны в нижней строке «—»
- **Файлы можно редактировать напрямую** в Obsidian — борда обновится автоматически
- **Колонки добавляются** созданием новой папки с числовым префиксом: `4-testing/`
- **Порядок колонок** можно переопределить вручную в настройках плагина
- **Done-колонки** для расчёта зависимостей настраиваются в Settings → Agent Kanban
