# Agent Kanban for Codex

The installable skill is in `skills/agent-kanban/SKILL.md`; installation is documented in `INSTALL-CODEX.md`. The board uses Markdown task files in column directories and epic files in `epics/`.

Find the board location, column names, and configured done columns in the vault and its project instructions before moving tasks. Preserve frontmatter and task descriptions, check ownership before claiming work, and follow the board owner's conventions for PRs, completion, cancellation, and archival. User and project instructions take precedence over generic examples.

For the generic field reference see `skills/kanban.md`. Its example column names and workflow are not required by the plugin.
