# Codex skill

Install the generic board skill with the Codex skill installer:

```sh
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo Derananer/obsidian-agent-kanban --path skills/agent-kanban
```

Restart Codex to discover it. The skill discovers the board and respects the workspace's own column and workflow conventions.
